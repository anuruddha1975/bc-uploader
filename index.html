Set up this device

This is a one-time setup on each phone or computer.

1Dropbox app key

Paste the App key of the Dropbox app you created (App console → your app → Settings). You will be taken to Dropbox and brought back here automatically.

Patient folders are created inside this folder, e.g. /BC_Cohort/BC-0123/

2Connecting to Dropbox

3Create a team passcode

Assistants type this passcode to unlock the app. Give it to them in person or by phone, never in the same message as the setup code.

4Setup code for assistants

Send this code to each assistant (WhatsApp or email is fine — it cannot be used without the passcode). This device is now set up as well.

Enter setup code

Paste the setup code you received from Dr. Anuruddha.
